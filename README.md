# Zeducation Content Library

The published site for Zeducation's teaching library: topics, frameworks,
activities and Pink Sheets, cross-linked and searchable.

**Live site:** https://pasitaua.github.io/zeducation-library/

## What this repo is

One file, `index.html`, holding the whole library as a self-contained page.
No build step, no dependencies, nothing to install. Open it anywhere.

## Where it comes from

Generated from the markdown in the private `pasitaua/Zeducation` repo by
`build_site.py`, and copied here on each update. **Do not edit `index.html`
by hand** — the next rebuild will overwrite it. Edit the markdown in the
source repo instead.

Internal research material (source notes and raw captures) is excluded from
this published build.
